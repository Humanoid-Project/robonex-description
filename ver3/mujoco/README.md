# RoboNex Mujoco (ver3)

## Structure

```text
mujoco/
├── README.md
├── build_mjcf.py
└── robot/
    ├── full/
    │   ├── robonex.xml
    │   ├── scene.xml
    │   ├── robonex_fixed.xml
    │   └── scene_fixed.xml
    └── legs/
        └── (same four files)
```

Both variants are generated by `build_mjcf.py` from `ver3/urdf/robonex_ver3.urdf` with the training joint limits in
`ver3/ver3_constants.json` and the leg actuator armature, frictionloss and damping in
`robonex_common.motors.MOTOR_PHYSICS` (none for rs00, rs05, rs10p). `full`: 24 position actuators (legs, arms, neck);
`legs`: 12 leg actuators, arms and neck fixed at 0 rad.

<br>

## Build

### `build_mjcf.py`

| Command | Option | Default | Description |
| --- | --- | --- | --- |
| - | `--variant` | `full` | Model variant (`full`, `legs`) |
| - | `--fixed-base` | Off | Weld the base in mid-air so the legs swing free |

```bash
# Example
cd ~/humanoid_project/robonex-description
.venv/bin/python -I ver3/mujoco/build_mjcf.py --variant full
.venv/bin/python -I ver3/mujoco/build_mjcf.py --variant full --fixed-base
```

| Output | Description |
| --- | --- |
| `robot/<variant>/robonex.xml`, `robot/<variant>/scene.xml` | No option |
| `robot/<variant>/robonex_fixed.xml`, `robot/<variant>/scene_fixed.xml` | `--fixed-base` |

<br>

## Run

```bash
# Example
python3 -m mujoco.viewer --mjcf=ver3/mujoco/robot/full/scene.xml
python3 -m mujoco.viewer --mjcf=ver3/mujoco/robot/full/scene_fixed.xml
```
