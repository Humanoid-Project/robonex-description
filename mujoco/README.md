# RoboNex Mujoco

## Structure

```text
mujoco/
├── README.md
├── build_mjcf.py
└── robot/
    ├── robonex.xml
    ├── scene.xml
    ├── robonex_fixed.xml
    ├── scene_fixed.xml
    └── box/
        ├── robonex_fixed.xml
        └── scene_fixed.xml
```

Every model is generated by `build_mjcf.py` from `urdf/robonex.urdf`, so all of them
carry the joint limits in `robonex_common.joints.ACTUATED_JOINTS`. The hand-maintained
`full_limit/` family was removed on 2026-09-08: it still held the pre-2026-09-07 sweep
ranges, which were narrower than the measured limits on 5 joints and wider on 7.

<br>

## Build

### `build_mjcf.py`

| Command | Option | Default | Description |
| --- | --- | --- | --- |
| - | `--fixed-base` | Off | Weld the base in mid-air so the legs swing free |
| - | `--collision-box` | Off | Box collision primitives instead of visual meshes; requires `--fixed-base` |

```bash
# Example
python3 mujoco/build_mjcf.py
python3 mujoco/build_mjcf.py --fixed-base
python3 mujoco/build_mjcf.py --fixed-base --collision-box
```

| Output | Description |
| --- | --- |
| `robot/robonex.xml`, `robot/scene.xml` | No option |
| `robot/robonex_fixed.xml`, `robot/scene_fixed.xml` | `--fixed-base` |
| `robot/box/robonex_fixed.xml`, `robot/box/scene_fixed.xml` | `--fixed-base --collision-box` |

<br>

## Run

```bash
# Example
python3 -m mujoco.viewer --mjcf=mujoco/robot/scene.xml
python3 -m mujoco.viewer --mjcf=mujoco/robot/scene_fixed.xml
python3 -m mujoco.viewer --mjcf=mujoco/robot/box/scene_fixed.xml
```
