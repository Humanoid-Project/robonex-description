# RoboNex Mujoco

## Structure

```text
mujoco/
├── README.md
├── build_mjcf.py
└── robot/
    ├── robonex.xml
    ├── scene.xml
    ├── robonex_fixed.xml
    └── scene_fixed.xml
```

Both models are generated by `build_mjcf.py` from `urdf/robonex.urdf`, so they carry the
joint limits in `robonex_common.joints.ACTUATED_JOINTS` and the actuator armature,
frictionloss, and damping in `robonex_common.motors.MOTOR_PHYSICS`.

<br>

## Build

### `build_mjcf.py`

| Command | Option | Default | Description |
| --- | --- | --- | --- |
| - | `--fixed-base` | Off | Weld the base in mid-air so the legs swing free |

```bash
# Example
python3 mujoco/build_mjcf.py
python3 mujoco/build_mjcf.py --fixed-base
```

| Output | Description |
| --- | --- |
| `robot/robonex.xml`, `robot/scene.xml` | No option |
| `robot/robonex_fixed.xml`, `robot/scene_fixed.xml` | `--fixed-base` |

<br>

## Run

```bash
# Example
python3 -m mujoco.viewer --mjcf=mujoco/robot/scene.xml
python3 -m mujoco.viewer --mjcf=mujoco/robot/scene_fixed.xml
```
