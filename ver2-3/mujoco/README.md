# RoboNex Mujoco

## Structure

```text
mujoco/
├── README.md
├── build_mjcf.py
└── robot/
    └── edu/
        ├── robonex.xml
        ├── scene.xml
        ├── robonex_fixed.xml
        └── scene_fixed.xml
```

Both models are generated by `build_mjcf.py` from `ver2-3/urdf/robonex_edu.urdf`, so they carry the training
joint limits in `ver2-3/ver2-3_constants.json` and the actuator armature, frictionloss, and damping in
`robonex_common.motors.MOTOR_PHYSICS`. Actuators: edu 12 legs. `neck_pitch_joint` is fixed at 0 rad;
`head_link` stays attached.

<br>

## Build

### `build_mjcf.py`

| Command | Option | Default | Description |
| --- | --- | --- | --- |
| - | `--variant` | `edu` | Model variant (`edu`) |
| - | `--fixed-base` | Off | Weld the base in mid-air so the legs swing free |

```bash
# Example
cd ~/humanoid_project/robonex-description
python3 ver2-3/mujoco/build_mjcf.py --variant edu
python3 ver2-3/mujoco/build_mjcf.py --variant edu --fixed-base
```

| Output | Description |
| --- | --- |
| `robot/<variant>/robonex.xml`, `robot/<variant>/scene.xml` | No option |
| `robot/<variant>/robonex_fixed.xml`, `robot/<variant>/scene_fixed.xml` | `--fixed-base` |

<br>

## Run

```bash
# Example
python3 -m mujoco.viewer --mjcf=ver2-3/mujoco/robot/edu/scene.xml
python3 -m mujoco.viewer --mjcf=ver2-3/mujoco/robot/edu/scene_fixed.xml
```
